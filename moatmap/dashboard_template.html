Query behind it
python -m moatmap.quotes

For each route x size x provider: request a live quote for the same asset pair and input amount.
cost_bps = (amount_in_usd - amount_out_usd) / amount_in_usd x 10,000
Both sides are priced with one 1Click price snapshot taken in the same run, for every provider, so the
figure is the all-in cost (spread + protocol fee + destination gas), not each provider's own estimate.
Failed quotes are kept with ok=0 and never filled in. Each point is the median across snapshots.

Query behind it
python -m moatmap.analyze   (function pricing_test)

"Thin" = routes where at most 2 rivals list both chains; "crowded" = 4 or 5.
Ratio = median NEAR cost on thin routes / median NEAR cost on crowded routes, per swap size,
computed separately for same-token routes (USDC>USDC, ETH>ETH) and different-token routes (BTC>ETH),
because NEAR's documented fee differs between them and mixing the two would manufacture a premium.
